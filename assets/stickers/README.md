# Sticker

Thư mục này đã có sẵn sticker WebP cắt từ 2 sheet AI. Bạn có thể thay bằng ảnh của mình.

## Cách thay

1. Chuẩn bị ảnh PNG nền trong suốt (hoặc WebP), kích thước khoảng 320–512 px.
2. Đặt vào thư mục này với đúng tên file bên dưới.
3. Nếu dùng PNG, giữ nguyên tên (ví dụ `tron_hi_hi_hi.png`) — web tự thử cả `.webp` và `.png`.
4. Chạy lại `npm.cmd run build` rồi deploy lại.

- `tron_kho_chiu` — khó chịu

- `tron_buon_ngu` — buồn ngủ
- `tron_di_thoi` — đi thôi

## Ba (a Mỏ)

Chưa có sheet sticker cho Ba. Trang sẽ dùng sticker SVG vẽ sẵn. Nếu muốn thay, thêm file `ba_cuoi.webp` hoặc `ba_cuoi.png` (và các biểu cảm `ba_quau`, `ba_chumom` nếu thích).

> Nếu thiếu bất kỳ file nào, web tự vẽ sticker SVG thay thế — không bị lỗi ảnh.
