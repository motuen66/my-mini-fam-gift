# Thư mục chứa Sticker PNG (AI sinh hoặc tự cắt)

Bạn chỉ cần bỏ các ảnh PNG nền trong suốt (transparent background) vào thư mục này!
Trang web sẽ tự động nhận diện theo tên file đã cấu hình trong `src/content/config.ts`.

## Tên file mẫu đề xuất:
### 1. Cho A mỏ (Ba):
- `ba_cuoi.png` - Ba cười tươi
- `ba_quau.png` - Ba giả vờ quạu / phụng phịu
- `ba_chumom.png` - Ba chu mỏ nịnh
- `ba_laixe.png` - Ba xách xe chở em đi ăn

### 2. Cho Em tròn (Mẹ):
- `me_cuoi.png` - Em tròn cười tít mắt
- `me_doian.png` - Em tròn đòi trà sữa / đồ ăn
- `me_nhongnheo.png` - Em tròn nhõng nhẽo đáng yêu
- `me_tha_tim.png` - Em tròn thả tim

### 3. Cho Hoành con (Con gái nuôi):
- `con_hahe.png` - Hoành con cười hả hê
- `con_quay.png` - Hoành con nghịch ngợm
- `con_honghot.png` - Hoành con hóng hớt drama

*Lưu ý: Nếu bạn chưa kịp bỏ ảnh PNG vào, trang web ĐÃ CÓ SẴN các sticker chibi vector tuyệt đẹp tự động hiển thị, không bao giờ bị lỗi ảnh vỡ!*
