# Thư mục âm thanh (Audio Assets)

Bạn có thể đặt 3 file MP3 vào thư mục này để trang web tự động phát giọng thật và bài hát thật của bạn:

1. `bgm.mp3` - Bài nhạc nền lofi hoặc tình cảm yêu thích của hai người.
2. `voice-boyfriend.mp3` - Đoạn ghi âm lời chúc của A mỏ gửi cho em tròn.
3. `voice-family.mp3` - Đoạn ghi âm lời chúc dành cho gia đình 3 người và Hoành con.

*Lưu ý: Nếu chưa có 3 file này, trang web vẫn hoạt động trơn tru 100% nhờ bộ tạo nhạc nền và đọc phụ đề tự động tích hợp sẵn!*
